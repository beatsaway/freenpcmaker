# Free NPC Maker

Procedurally generate a full character in one place: mesh, texture, rig, and animation. Great for indie projects.

## Run

```bash
npm install
npm run dev
```

Or on Windows: double-click `start.bat` (opens http://127.0.0.1:8770/demo/index.html).
